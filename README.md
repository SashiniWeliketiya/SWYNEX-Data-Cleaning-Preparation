# Data Cleaning & Preparation - Mall Customers Dataset

## Overview
This project involves cleaning and preparing a customer segmentation dataset (`Mall_Customers.csv`) as part of the SWYNEX Technologies Internship Task 1.

## Identified Issues in Raw Data
1. **Missing Values:** Handled missing entries in numerical columns using the median.
2. **Duplicates:** Checked and removed duplicate customer records.
3. **Inconsistent Formatting:** Standardized the `Genre` column to ensure uniform casing and remove trailing spaces.

## Tools Used
* Python (Pandas Library)

## Results
The dataset has been successfully sanitized, formatted, and saved as `cleaned_mall_customers.csv`, ready for exploratory data analysis (EDA) and clustering algorithms.
